\section{Conclusion}
A tool call is where an agent's text becomes an action. On a public benchmark, a fail-closed monitor there kept all but \AdTiersGoalUnreviewed{} of a fully hijacked agent's goals from running without a person at \AdTiersAsks{} approval requests per benign task, and all of them at \AdConsAsks{}, using policies derived from tool descriptions. Three lessons carry beyond our implementation: enforcement must be written for each host's failure semantics, because hosts let calls through when hooks fail; typed argument semantics remove whole classes of string-rule failures; and a statistical guarantee about reviewers is not containment, so calibrated deferral is safe only behind an eligibility boundary that information flow helps draw.
